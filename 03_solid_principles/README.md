SOLID Principles
SOLID principles are 5 important rules for writing good object-oriented code.
These principles help you write software that is easy to understand, easy to modify, and easy to maintain.
By following SOLID, your code becomes cleaner and more professional.


SOLID Principles
S → Single Responsibility Principle (SRP)
O → Open/Closed Principle (OCP)
L → Liskov Substitution Principle (LSP)
I → Interface Segregation Principle (ISP)
D → Dependency Inversion Principle (DIP)
